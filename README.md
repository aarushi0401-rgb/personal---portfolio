
# Personal Portfolio Website

## Project Description
This is a simple personal portfolio website
created using HTML5.

## Features
- Header and navigation bar
- Hero section
- About Me section
- Profile picture
- Projects section
- Technical Skills table
- Contact form
- Footer

## Technologies Used
- HTML5
- CSS

## Project Structure

portfolio-project/
- index.html
- README.md


## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Purpose
The purpose of this project is to learn
HTML structure, semantic elements,
tables, lists, links and forms.
